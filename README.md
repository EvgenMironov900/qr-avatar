# 🔲 Генератор аватарки с QR-кодом

**Версия 1.1** | [Открыть веб-версию](https://EvgenMironov900.github.io/qr-avatar/) (если включен GitHub Pages)

Это полностью **автономное** веб-приложение, которое позволяет создать уникальную аватарку: QR-код с вашей фотографией в центре. В отличие от обычных генераторов, здесь можно закодировать любой текст (приветствие, номер телефона, адрес, поздравление), а не только ссылку.

## 🚀 Основные возможности
*   **Автономность:** Работает без интернета после скачивания.
*   **18 стилей?** (Нет, здесь только 1 стиль, но зато свой). *— Шутка, мы оставим просто список фич.*
*   **Гибкость:** Настройка размера фото в центре QR-кода (от 20% до 50%).
*   **Экспорт:** Скачивание готовой аватарки в высоком разрешении (1600x1600).
*   **Адаптивность:** Отлично работает на ноутбуках, планшетах и смартфонах.

## 🛠️ Как запустить локально (без интернета)

Чтобы приложение работало автономно, вам нужно **скачать два файла** и положить их в одну папку:

1.  **`index.html`** — основной файл приложения (интерфейс).
2.  **`qrcode.min.js`** — библиотека для генерации QR-кодов (размером всего ~20 КБ).

**Инструкция:**
1. Скачайте оба файла из этого репозитория.
2. Положите их в любую папку на вашем компьютере (например, `qr-avatar`).
3. Откройте файл `index.html` двойным кликом в любом современном браузере (Chrome, Firefox, Edge).
4. Приложение готово к работе! Интернет больше не нужен.

## 📱 Использование на телефоне
1. Скачайте оба файла на телефон (или откройте веб-версию по ссылке выше).
2. Загрузите фотографию из галереи.
3. Введите текст или ссылку.
4. Нажмите «Сгенерировать» и сохраните результат кнопкой «Скачать» (или кликом по холсту).

## 🧰 Технологии
*   HTML5 / CSS3
*   JavaScript (Vanilla)
*   Библиотека `qrcode-generator` (v2.0.4) для отрисовки QR-кодов на Canvas.
